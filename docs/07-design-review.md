# 07 · Дизайн-ревью 2026-09-18: что было не так и что переделано

Тригер — прямая претензия клиента: «UI очень детский, непонятный шрифт, ничего не чётко,
видно, что сгенерировано AI». Ревью сделано по факту, а не по вкусу: ниже причины, которые
можно пощупать в коде и в файлах, и что с ними сделано.

## 1. Диагноз: четыре претензии → четыре измеримые причины

| Претензия          | Настоящая причина (было)                                                                                                                               | Почему это читается именно так                                                                                                                                                                                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «непонятный шрифт» | дисплей — **Unbounded** (варейбл, clamp до `5.2rem`, рост 4.6vw)                                                                                       | геометрический «крипто»-шрифт с широкими буквами: на заголовках выглядит как обложка токена, а не вывеска выставочного центра; кириллица в нём вторична по построению                                                                                                      |
| «ничего не чётко»  | `--line: rgba(22,33,28,.14)`, `--r: 20px`, `--r-lg: 32px`, `--r-pill: 999px`, `--shadow: 0 30px 60px -40px`, hover `translateY(-3px)`                  | всё на полупрозрачных границах, скруглено и «парит» на мягкой тени: глаз не находит ни одной жёсткой линии → нет структуры, есть «пузыри»                                                                                                                                  |
| «детский»          | масштаб: `h2 3.2 / h3 1.9 / h4 1.28 / body 1.1rem` (шаги ~1.3), `--pad` и `--sec` раздуты, 1 картинка на страницу                                      | слабая разница размеров + много воздуха + мало данных = «лендинг», а не отраслевой ресурс; у охтаря и agravia плотность фактов выше при меньших отступах                                                                                                                   |
| «видно, что AI»    | 10 рендеров в `public/images/` **как главный визуал первого экрана** + та же тёплая палитра (`--cream #f7f4ec`, `--gold`, `--sage`), что и у генерации | на рендерах нет ни одной читаемой вывески/логотипа, модули стендов бесконечно одинаковы, фермы симметричны, пол стерильно чистый (ни кабеля, ни упаковки), лица «стоковые»; а крем+золото сайта совпадают с грейдом этих картинок — сайт и «фото» выглядят как один промпт |

Отдельно: `alt=""` был на 136 из 269 `<img>` (аудит разрешал пустой alt) и `favicon.svg` был
скруглённым квадратом с нарисованными буквами — оба признака того же происхождения.

## 2. Что сделано

| Слой                 | Было                                                                | Стало                                                                                                                                                                         |
| -------------------- | ------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| дисплей              | Unbounded, до 5.2rem                                                | **Inter Tight Variable** 750, `-.028em`, `--t-hero clamp(2.05rem…3.4rem)`                                                                                                     |
| текст                | Onest                                                               | **Golos Text Variable** (Paratype; нейтральный «инженерный», табличные цифры, родная кириллица)                                                                               |
| подписи/числа        | тот же body-шрифт, 600                                              | **JetBrains Mono Variable**, `.72rem`, uppercase, `letter-spacing .12em`                                                                                                      |
| палитра              | cream `#f7f4ec` + gold `#c58a2e` + sage `#cbdcca` + paper `#fffdf7` | бумага `#fff`, холодные листы `#f4f5f3`/`#ebeeec`, графит `#0e1411`, один зелёный `#0f2b1c`; **золото из UI убрано** (токены переименованы в значениях, а не в 18 селекторах) |
| границы              | полупрозрачные `rgba(ink,.14)`                                      | сплошные `#dde1dd` / hover `var(--ink)`                                                                                                                                       |
| радиусы              | 12 / 20 / 32 / pill                                                 | **2 / 3 / 4 / 2px** (капсул больше нет — токен `--r-pill` стал 2px, поэтому править 11 мест не пришлось)                                                                      |
| тени                 | 2 мягкие тени + hover-подъём                                        | `none`; в CSS остались только 2 `box-shadow` фокус-ринга `:focus-visible`                                                                                                     |
| карточки             | тень + translateY(-3px)                                             | 1px рамка → на hover рамка становится `--ink`, у `.ev__img img` снимается обесцвечивание (единственная «анимация»)                                                            |
| `.stat`              | цифры Unbounded до 2.7rem, цвет evergreen                           | `--ink`, до 2.05rem, **табличные**, сверху 2px-линейка                                                                                                                        |
| кнопки               | `padding .95/1.6`, hover подъём+тень, gold-вариант                  | `padding .78/1.25`, плоские, первичная = **графит**, ghost = 1px `--line` → hover `--ink`                                                                                     |
| чипы                 | пастель `gold-soft`/`#e4f0e2`, pill                                 | моно-лейбл 2px, `--moss` solid (белый на moss 7.8:1 — работает и на светлом, и на тёмном полу)                                                                                |
| первый экран события | размытый рендер зала на 42%                                         | **размерная сетка зала** (64px модуль) + счётчик + `dl` фактов; фото уходит из хиро совсем                                                                                    |
| alt                  | 136 пустых                                                          | 0 пустых; правило аудита ужесточено (`alt=""` принимается только с `role="presentation"`)                                                                                     |
| favicon              | скруглённый квадрат с буквами                                       | знак = корпус зала: оболочка, три модуля стендов, сервисный проход, подиум-линия; 0 скруглений                                                                                |
| og-карточка          | фото на градиентной вуали + золото                                  | сетка модулей, hairline-правила, стек-вордмарк, моно-дескриптор, слева-фото как **серая панель**, отделённая 1px                                                              |
| изображения-заглушки | цветные, выглядели как съёмка                                       | `--ph-filter: grayscale(1) contrast(1.06)` на `img[src^='/images/']` — одна строка, которую нужно удалить в день, когда придут настоящие фото                                 |

## 3. Проверки после переделки

- контраст: `--ink` на бумаге **18.6:1**, `--ink-60` **7.9:1**, `--moss` на светлом **6.5:1**,
  белый на `--evergreen` **15.2:1**; кикер и `.mono-label` были подняты с `--ink-40` (4.2:1 на
  креме — этого мало для 11.5px) на `--ink-60`
- в собранном CSS: декоративных `box-shadow` — 0 (только 2 фокус-ринга), `border-radius` —
  максимум 4px, `translateY`-ховеров — 0
- `npm run build && npm run audit:seo` → 152 страницы, 0 замечаний; `scripts/qa-independent.py`
  (отдельный чекер) → 0 новых типов замечаний; `node scripts/build-hosts.mjs --mode subdomain` →
  6 хостов, аудиты чистые, `check-hosts`: «hosts agree»
- шрифты: у **Archivo** (первая кандидатура) в fontsource нет кириллического сабсета —
  для RU не годится, проверено по `files/`; Inter Tight, Golos Text и JetBrains Mono — есть
  (`dist/_astro/*.woff2` включает `*-cyrillic-wght-normal`)

## 4. Фотозадание (то, что закрывает «видно, что AI» окончательно)

Рендеры **нельзя** публиковать как съёмку центра — они остаются только заглушками в макете.
Нужно 22 кадра; имена файлов уже зафиксированы, замена 1-в-1 по имени, после чего удаляется
строка `--ph-filter` и ничего больше.

| #     | Файл                                                               | Кадр                                                                                                 | Кроп  |
| ----- | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | ----- |
| 1     | `hero-hall.jpg`                                                    | общий план зала с монтажом (чтобы были леса, ящики, люди в работе)                                   | 16:9  |
| 2     | `venue-exterior.jpg`                                               | фасад днём, с вывеской и въездом фур                                                                 | 16:9  |
| 3     | `venue-conference.jpg`                                             | конференц-зал со сценой и залом участников                                                           | 3:2   |
| 4     | `samarkand.jpg`                                                    | город (Регистан или площадь) — один кадр, без «открыточного» HDR                                     | 3:2   |
| 5–10  | `event-foodera / buildpro / agropro / worldedu / ecom / promotors` | по одному реальному кадру каждой редакции: стенд + стендист в кадре, читается бренд                  | 16:10 |
| 11–16 | `hall-*.jpg` (6)                                                   | залы по одному: пустой зал, вид с балкона, план зоны, электро-щиток, погрузка, кафе                  | 3:2   |
| 17–22 | `detail-*.jpg` (6)                                                 | крупно: стойка ресепшн, навигация, брендирование стенда, регистрация, переводчик, раздача материалов | 1:1   |

Технические требования: съёмка на месте (не рендер, не реток чужого зала), EXIF сохранён,
длина стороны ≥ 1600px, sRGB, JPG q≥80, без водяных знаков; на кадрах должны читаться **тексты**
(вывески, брендволлы, экраны) — именно отсутствие читаемого текста выдает генерацию; людей
снимать с согласия, детей — нельзя; ни один кадр не должен повторять ракурс другого.

## 5. Что я предлагаю решить дальше (вкус = выбор клиента, не мой)

1. **Светлый или тёмный дефолт.** Сейчас: светлая бумага, тёмные «полосы» (хиро, CTA, футер).
   Альтернатива — инвертировать (тёмная оболочка, светлые контентные блоки): дороже выглядит,
   тяжелее читать длинные тексты, хуже для печати КП.
2. **Один сигнальный цвет.** Сейчас действий нет цветного акцента вообще (графит + зелёный).
   Для дедлайнов и «осталось 38 стендов» просят добавить второй цвет — предлагаю кирпич
   `#a33518` (= `--danger`) только на статусы, не на кнопки. Нужен ли он — решать вам; третий
   акцент без причины я не ввожу.
3. **OG по хостам.** Сейчас одна общая карточка. Правильно — генерировать `og/<event>.jpg`
   с датами конкретного шоу из `src/data/events.ts` и отдавать её на хосте шоу; шаблон уже
   параметризован, нужно ~20 строк в `scripts/build-assets.mjs`.
4. **Прайс вместо «по запросу».** Как только клиент отдаёт тарифы, блок `.stat`/`dl` уже умеет
   табличные числа; появятся настоящие таблицы, и текст «уточняется» уйдёт из 6 мест.

## 6. Что специально не трогали

Ни структура URL, ни хост-модель, ни тексты, ни данные событий, ни SEO-контракт (`docs/02`), ни
правила аудита (кроме ужесточения alt/loading). Претензия была к визуальной подаче — изменена
только подача: 2 шрифта заменены, палитра/радиусы/тени/масштаб/хиро/иконка/og переписаны,
контент не тронут ни на символ.
